# Штойк Валерия УИБО-14-24

### Задание 1

**Решение задания:**

**1. Использованные для ввода данные.**

Поле Email/Login: ' OR 1=1;--

Поле Password: 123

**2. Под каким пользователем вам удалось войти.**

admin@juice-sh.op

**3. Ваши предположения, почему удалось войти именно под этим пользователем.**

SQL-инъекция ' or 1=1;-- обошла проверку пароля и вернула всех пользователей из базы данных. Приложение использует первую запись из результата, которая обычно принадлежит администратору.

**4. Где хранится аутентификационная информация, что она из себя представляет и как передаётся в каждом запросе.**

Основное место: Cookies (токен сессии)

Дополнительно: Local Storage (email, basket ID)

Что представляет: JWT-токен в base64 формате, содержащий ID пользователя, email и хэш пароля

Как передаётся: Автоматически добавляется браузером в заголовок Authorization или Cookie каждого HTTP-запроса
