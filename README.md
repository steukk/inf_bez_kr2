### Ответы на вопросы:

- **Что такое SQL инъекция?**

SQL-инъекция — это уязвимость веб-приложений, позволяющая злоумышленникам внедрить вредоносный код в SQL-запросы, чтобы получить несанкционированный доступ к базе данных.
  
- **Почему ввод строки ' or 1=1;-- позволил войти в аккаунт администратора?**

Потому что эта строка:

- Ломает оригинальную структуру SQL-запроса
- Добавляет условие OR 1=1 (всегда истинное)
- Комментирует остаток запроса (--)
- Возвращает всех пользователей, и приложение использует первого (администратора)


- **Как защитить web-ресурс от подобного рода атак?**

- Проверять и экранировать пользовательский ввод
- Принцип минимальных привилегий для учетной записи БД
- Не выводить детальные SQL-ошибки пользователям
- Использовать ORM-библиотеки
- Регулярное тестирование безопасности

- Что такое cookie?

Cookie - это данные, которые сайт сохраняет в браузере и которые автоматически передаются серверу при каждом запросе. Они используются для аутентификации, хранения настроек и идентификации пользователя.


- Какие меры могут быть использованы для устранения выявленной
уязвимости?

Чтобы устранить уязвимость, нужно:
  - не хранить чувствительные данные в cookie,

  - использовать флаги HttpOnly, Secure, SameSite,

  - ограничивать время жизни токена,

  - проверять токен на сервере,

  - применять HTTPS и защиту от XSS.
